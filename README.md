# 🧪 MERNLAB — MERN Stack Laboratory & Applied Engineering Experiments

A comprehensive, production-aligned laboratory curriculum and practical code repository covering core full-stack competencies across **MongoDB**, **Express.js**, **React.js**, and **Node.js**.

---

## 📌 Repository Overview

This repository contains structured, reproducible laboratory experiments designed for MCA and Computer Science coursework. Each experiment demonstrates foundational concepts, design patterns, security practices, and ends with a complete full-stack practical project.

---

## 📂 Laboratory Curriculum & Experiments

| Lab # | Experiment Title | Core Topics | Status |
| :---: | :--- | :--- | :---: |
| **Lab 1** | **Express.js RESTful API Architecture** | HTTP methods, route parameters, JSON body parsing, custom middleware, error handling | ✅ Complete |
| **Lab 2** | **MongoDB & Mongoose Data Modeling** | Schemas, validations, relational references (`populate`), CRUD operations, indexing | ✅ Complete |
| **Lab 3** | **Secure JWT Authentication & Security** | Password hashing with Bcrypt, JWT issuance and verification, protected route middleware | ✅ Complete |
| **Lab 4** | **Modern React Component Architecture** | Functional components, Hooks (`useState`, `useEffect`), synthetic events, conditional rendering | ✅ Complete |
| **Lab 5** | **Client-Server Integration & State** | Cross-Origin Resource Sharing (CORS), Fetch/Axios API, loading states, notification toasts | ✅ Complete |
| **Lab 6** | **Capstone Project: Student Task & Grade Tracker** | Complete full-stack MERN application with database persistence and responsive UI | ✅ Complete |

---

## 🚀 Running the Experiments

### Lab 1: Express REST API
```bash
cd experiment-01-express-basics
npm install
node server.js
```

### Lab 2: MongoDB CRUD
```bash
cd experiment-02-mongodb-crud
npm install
node server.js
```

### Lab 3: JWT Authentication
```bash
cd experiment-03-auth-jwt
npm install
node server.js
```

### Lab 6: Capstone Student Task & Grade Tracker
```bash
cd experiment-06-student-tracker-app
npm install
npm start
```
